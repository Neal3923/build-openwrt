🛠️ OpenWrt智能编译工具

面向x86_64的可视化固件编译平台 · 支持GitHub Actions与Ubuntu本地服务器

1
🚀 项目准备
使用GitHub Actions：
  • Fork项目到自己的GitHub账户
  • 在 js/config-data.js 中修改 GITHUB_REPO
  • 打开Actions页面并启用Fork中的工作流
  • 在Settings → Pages中选择从默认分支的根目录部署

Pages地址通常为：
https://用户名.github.io/仓库名/
2
🔑 配置Token
推荐使用fine-grained Token：
  • Repository access只选择自己的编译仓库
  • Contents设置为Read and write
  • Actions设置为Read-only
  • 不要把Token写入源码或提交到仓库

不想配置网页Token时，可在Actions页面使用“Run workflow”手动编译。
3
🎯 选择源码与分支
当前支持：
  • OpenWrt官方：main、25.12、24.10、23.05
  • Lean's LEDE：master及三个历史快照
  • ImmortalWrt：master、25.12、24.10、23.05
  • Lienol：25.12、24.10、23.05、19.07

当前目标设备固定为x86_64 Generic。根分区容量可设置为128–4096 MiB，默认512 MiB。
4
🔧 选择插件
插件分类：
  • 代理：SSR Plus+、PassWall、OpenClash
  • 网络：AdGuard Home、DDNS、UPnP、Bandix
  • 系统：Docker、DiskMan、KVM、TTYD、WOL
  • 多媒体：Aria2、Transmission、Samba4、MiniDLNA
  • 主题：Argon及其设置界面

网页和工作流会同时检查代理互斥、Intel/AMD KVM互斥及分支兼容性。
5
☁️ Actions编译
操作流程：
  • 在网页完成四步配置
  • 选择GitHub Actions并开始编译
  • 进度根据Actions实际步骤显示
  • 成功后从Releases下载固件和SHA256校验文件

项目不再上传重复的Actions Artifact。完整编译可能持续数小时，以Actions页面状态为准。
6
🖥️ 本地服务器编译
当前支持Ubuntu 24.04。安装依赖可以使用root或sudo，正式编译必须使用普通账号，不要求创建actions用户。
git clone https://github.com/Neal3923/build-openwrt.git "$HOME/build-openwrt" cd "$HOME/build-openwrt" sudo bash ./script/setup-local-builder.sh
Fork用户可替换为自己的仓库地址。网页第4步选择“本地服务器”，复制本次编译命令即可。脚本会使用全部CPU线程。
7
📁 本地产物与清理
默认目录为 $HOME/build-openwrt-local：
  • runs：独立源码与诊断日志，超过24小时后安全清理
  • cache：下载缓存和ccache，不自动删除
  • output：固件、校验文件和完整日志，不自动删除

同一工作根目录一次只运行一个任务，避免缓存损坏或内存不足。
8
🔐 固件默认设置
  • 管理地址：10.0.0.1
  • 用户名：root
  • 密码：root

这些值用于全新刷写或恢复出厂设置。检测到root已有密码时会保留当前地址和密码；首次登录后请立即修改默认密码。

🔍

💾

校验固件

刷写前使用发布页中的sha256sums.txt核对文件

⚠️ 重要提醒
  • 默认密码：root/root安全性很低，首次登录后必须修改
  • Token：不要写入源码，不要在公共电脑上保存
  • 刷机风险：刷写前确认x86_64目标并备份现有系统和配置
  • KVM：Intel与AMD模块不能同时选择，请按CPU厂商选择
  • 网络：编译需要下载大量代码和依赖，请确保连接稳定
